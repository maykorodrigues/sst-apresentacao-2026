Acesse https://github.com/new e crie um novo repositório público chamado `sst-apresentacao-2026`

### Passo 2: Fazer push
```bash
cd lucas-cs/
git add -A
git commit -m "Initial commit: Apresentação Sucesso do Cliente"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/sst-apresentacao-2026.git
```

### Passo 3: Ativar GitHub Pages
1. Vá para Settings > Pages
2. Selecione "main branch" como source
3. Aguarde 1-2 minutos
